# senior-project-practice

Project Information

This repository was created as part of a Senior Project Git and GitHub practice exercise. The goal of the project is to demonstrate basic version control workflows, including repository creation, branching, development, and collaboration using GitHub.

Repository Structure
senior-project-practice/
│
├── README.md
└── app.py

Project Objective

The application is a simple developer profile program that displays:

Student name
Academic major
Area of technology interest
A skill goal for the Senior Project experience

Development Workflow

This project follows a feature branch workflow. Development is performed on the branch:

feature/student-info

Branch → Code → Commit → Push → Pull Request → Review → Merge

Rather than making changes directly on the main branch, all updates are implemented and tested within the feature branch before being merged.

Technologies Used
Python
Git
GitHub
Learning Outcomes

Through this project, students gain experience with:

Creating and managing GitHub repositories
Cloning repositories to a local machine
Working with Git branches
Tracking and committing code changes
Writing basic programs
Following version control best practices
Collaborating using GitHub workflows
